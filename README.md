# 公共标识多语言校对台

用于公共空间标识译文录入、术语校验、版面风险预览和紧急修订的本地优先工作台。示例包含轨道交通、商场、公园和医院标识。

## 功能

- 录入中文原文、目标语言、适用场景和法规/规范提示。
- **地名条目与标识两侧分管**：「地名管理」侧由地名管理部门维护标准拼写、生效与废止（含历史记录）；「标识校对台」只登记牌子引用了哪些地名、引用时牌面是什么写法，以及审校状态。
- **整包导入拼写表**：支持 JSON（`{places:[{placeId,name,spelling,status}]}`）或 TSV（表头含 name、spelling）。整包解析失败时一条数据都不落地，输入内容保留，改完可重试，已退回的标识原样保留。
- **按现行写法对账**：拼写表生效后自动对账。引用到改动地名的标识退回「需修改」并列出前后差异（旧写法 → 现行写法、废止单独标注），其余标识照旧；还是草稿、尚未提交的译文不改状态、不改内容，只列差异。
- 校对员可一键按现行写法改正并核销，或自行改好后核销；牌子改回现行写法后再次对账会自动核销该地名的差异。
- **旧稿升级**：本地旧版数据（schema 1）首次打开时按牌面拼写认领到地名条目；一个拼写对上多个地名、或一个地名在稿中有多种写法时不自动选边，统一摆到「地名管理」的待裁决面板人工认领。
- 实时预览 320、480、720、960 像素宽度和 28—88 像素字号下的换行、截断和溢出风险。
- 统计预计行数、字符数和未命中的必选术语，并给出高风险、需留意、版面安全三级判断。
- 为每条译文绑定固定术语；术语与译文不一致时高亮告警，可逐条确认或删除。
- 支持草稿、待确认、需修改、已确认四种审校状态。
- 添加审校意见、回复并标记解决状态。
- 保存最多 12 个版本快照，按词/字符比较旧版与当前译文，绿色表示新增、红色表示删除。
- 生成只读预览链接；链接读取当前浏览器保存的本地版本，不提供服务端数据。
- 紧急修订模式会把已确认标识重置为待审校，强制重新确认；修订后可通过状态按钮回到审校流程。
- 多步撤销/重做、本地自动保存、断网继续编辑。
- 键盘操作：`J`/`K` 切换标识，`[`/`]` 切换预览宽度，`-`/`=` 调整字号。

## 技术栈

- Qwik 1 + Qwik City + TypeScript
- DaisyUI 5 + Tailwind CSS 4
- Qwik City 静态适配器
- 浏览器 `localStorage`
- nginx 静态部署

## 开发

```bash
npm install
npm run dev
```

## 构建与预览

```bash
npm run build
npm run preview
```

生产构建输出到 `dist/`，由 Qwik City static adapter 生成可静态部署文件。

## Docker

容器内 nginx 监听 `80`，宿主端口按根端口表映射为 `10008`。

```bash
docker build -t sologsb-1008 .
docker run --rm -p 10008:80 sologsb-1008
```

访问 `http://localhost:10008`。

## 数据说明

项目和版本数据保存在当前浏览器 `localStorage`。只读预览链接仅对保存过同一浏览器本地数据的设备有效，不回传或公开业务数据。
